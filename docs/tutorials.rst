Tutorials
=========

Below you can find tutorials that highlight the functionalities of ``exogaia``. All tutorials can be downloaded as `Jupyter notebooks <https://github.com/tomasstolker/exogaia/tree/main/docs/tutorials>`_. Please `create an issue <https://github.com/tomasstolker/exogaia/issues>`_ if you encounter any problems or unexpected behavior.

.. tip::
   Detailed descriptions of all classes, functions, and parameters are available in the
   `API documentation <https://exogaia.readthedocs.io/en/latest/modules.html>`_.

- :doc:`tutorials/single_star`
  – Fit the epoch astrometry with a single star model

- :doc:`tutorials/acceleration`
  – Fit the epoch astrometry with an accelerating star model

- :doc:`tutorials/binary_orbit`
  – Fit the epoch astrometry with a orbit model

- :doc:`tutorials/completeness`
  – Compute a DR4/DR5 completeness map for a Gaia source
