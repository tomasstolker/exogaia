*exogaia*
==========

.. container::

    |PyPI Status| |Python Versions| |CI Status| |Docs Status| |Code Coverage| |Code Quality| |License|

*exogaia* is a tool for analyzing Gaia epoch astrometry. The package has been released on `PyPI <https://pypi.org/project/exogaia/>`_ and is actively developed and maintained on Github.

Documentation
-------------

Documentation can be found at `http://exogaia.readthedocs.io <http://exogaia.readthedocs.io>`_.

Contributing
------------

Contributions are welcome so please consider `forking <https://help.github.com/en/articles/fork-a-repo>`_ the repository and creating a `pull request <https://github.com/tomasstolker/exogaia/pulls>`_. Bug reports and feature requests can be provided by creating an `issue <https://github.com/tomasstolker/exogaia/issues>`_ on the Github page.
